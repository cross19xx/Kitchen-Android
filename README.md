# Kitchen Sink Android

A collection of projects I'm working on that are built with Native Android (either using Java or Kotlin)

## Reason for this repository

To introduce myself, I'm a mobile and web fullstack engineer. I spent the first years of my professional career building native mobile applications, in Java and Objective C — sometimes with the then early React Native.

But after about 4 years, I pivoted to solely React Native projects, and this sidelined native development. With that focus meant I stopped keeping up with the latest updates in Kotlin and Java in relation to Native Android development.

This repository contains projects that I am building to hone my skills in Native Android Development.

## Notes

- Each project will be treated as a professional project, with tests, icons, documentation, and end-to-end release notes.
- There is the propensity for each project's architecture to be different, and that's because I'll be refining the skills as I proceed.
- I'll try to limit AI usage to only scaffolding and code explanation. I won't be using AI to write portions of code that I won't be reading.
